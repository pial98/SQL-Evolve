# SQL-Evolve

This project implements a retail sales data warehouse using MySQL.  
It includes schema design, data population, analytical queries, and business insights.

- `schema.sql` – Database schema, constraints, foreign keys, index, and views
- `data.sql` – Data insertion and transactions
- `eda.sql` – Exploratory Data Analysis queries

 Data Model
- Fact table: `fact_sales`
- Dimension tables: `store`, `product`, `customer`, `calendar`, `province`

How to Run
1. Execute `schema.sql`
2. Execute `data.sql`
3. Execute `eda.sql`
